- Portal data is read/written from the browser client with RLS; roles live in public.user_roles and the first signup becomes admin (trigger) — keeps access server-enforced without extra API layers.
- Fee receipt numbers are generated by a DB trigger only when status is 'paid' — a receipt can never exist for an unpaid fee.
- Admin and head teacher share student management; head teacher role changes are teacher-only and exclude leadership accounts, enforced by RLS as well as UI checks.
